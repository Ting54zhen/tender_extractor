# samples · 脱敏样本（进 git）

本目录存放**脱敏后**的采购需求样本，供团队成员共享、跑通流程与回归测试使用。

## 与 data/ 的区别

| 目录 | 内容 | 是否进 git |
|------|------|-----------|
| `samples/`（本目录） | 脱敏样本（单位名/联系人/电话已打码） | 是 |
| `data/` | 真实样本与抽取输出（`.gitignore` 已隔离） | 否 |

## 脱敏要求

放入本目录前，必须对文档做以下处理：

1. 单位名称 →「某单位」（如「广州市××分局」→「某市公安分局」）；
2. 人名、联系电话、邮箱、地址 → 打码；
3. 保留章节结构、表格形态、金额与日期等**抽取相关特征**——脱敏不能破坏解析难度；
4. 文件名同步脱敏（不含真实单位名）。
